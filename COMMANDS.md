## 6. Interactive Terminal Shortcuts & Controls

| Shortcut / Action | Function |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Toggle terminal window open/close anywhere on the website. |
| <kbd>Tab</kbd> or <kbd>→</kbd> (Right Arrow) | Auto-completes commands and file names based on active buffer. |
| <kbd>↑</kbd> (Up Arrow) | Navigate backwards through executed command history. |
| <kbd>↓</kbd> (Down Arrow) | Navigate forwards through executed command history. |
| **Drag Header** | Click and drag the terminal top bar to move it anywhere on screen. |
| **Edge Resizing** | Drag the left or bottom window borders to resize the terminal dimension. |
| **Close Button (<kbd>×</kbd>)** | Closes the floating terminal window. |
